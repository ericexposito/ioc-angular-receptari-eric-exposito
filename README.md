# Receptari

## Autor/a

Eric Expósito Torres

## Descripció

Aplicació per consultar i desar receptes de cuina, amb els seus ingredients i passos d'elaboració. 
Projecte base d'Angular creat per al mòdul DA2_OA01 - Programació Avançada amb Angular, que s'ampliarà durant el semestre.

## Versions utilitzades

- Node.js: 24.21.0
- npm: 11.19.0
- Angular CLI: 22.2.1
- Angular: 22.2.1
- Git: 2.55.0

## Com crear i executar el projecte

Comanda utilitzada per crear el projecte:

```
ng new ioc-angular-receptari-eric-exposito --routing --style=scss --ssr=false --standalone --file-name-style-guide=2016 --skip-git --package-manager=npm
```

Per instal·lar les dependències i executar el projecte en mode desenvolupament:

```
npm install
ng serve
```

L'aplicació queda disponible a http://localhost:4200
